# The Fit Letter

A weekly training-programme newsletter for people who already lift. The
design reads like a gym chalk board, not a tech dashboard: chalk-dust grey
ground, ink-black type, and one iron-oxide red pulled from a 25kg competition
plate rim. Anton numerals — set as oversized rep schemes like `5×5` and `3×8`
— are the page's signature, clipping behind a horizontal-scroll band of the
week's sessions; Barlow carries the copy in flat, imperative programme-card
voice. Motion is rationed to the numerals only, which roll up like a rep
counter on entry.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000 (or whichever port you pass with `-p`).

```bash
npm run build   # production build, zero TS errors
npm run lint    # eslint
```
